# 네이버 블로그 자동 원고 — 마스터 프롬프트

> 이 파일은 Claude가 **글을 쓸 때마다 가장 먼저 읽는 지시서**입니다.
> 빈칸과 키워드는 Claude가 직접 조사해서 채웁니다.

---

## 0. 블로그 정보

- 블로그: `https://blog.naver.com/ji_hoo_mom`
- 주제: **결혼 · 육아 · 살림 · 인테리어** (+ 수익용 CPA 글: 여행·쇼핑 등 판매 링크가 있는 글)
- 독자: 결혼 준비 중이거나 아이를 키우며 살림하는 2040 여성
- 말투: 친근한 존댓말("~했어요", "~더라고요"), 솔직한 후기 느낌
- 목표: **네이버 검색·홈피드 유입(조회수)** 과 **CPA 판매 전환**

## 1. 글 유형 고르기

| 유형 | 언제 | 템플릿 |
|---|---|---|
| **CPA형** | 판매 링크가 있을 때 (블로그 주인이 링크를 주면) | 아래 3-A |
| **홈피드형** | 이슈·반전이 있는 주제 (네이버 홈피드 노출용) | 아래 3-B |

매일 자동 원고는 **정보형 또는 홈피드형**으로 쓴다. CPA형은 판매 링크가 없으면 쓰지 않는다 (링크를 지어내지 않는다).

## 2. 공통 절차 (모든 글)

1. **공부한 내용 읽기**: `naver/learnings.md` 전체, `naver/keywords.md`, 최근 원고 10개 제목 (주제 중복 금지)
2. **키워드 조사 (Claude가 직접)**:
   - 웹 검색으로 결혼·육아·살림·인테리어의 **요즘 뜨는 검색어**를 찾는다 (오늘의집 검색 트렌드, 뉴스, 시즌 이슈)
   - 날짜·계절·행사를 반영한다 (예: 9~10월 = 가을 이사·결혼 시즌·환절기 육아·추석 후 정리)
   - 메인 키워드 1개 + 보조 키워드 2~3개. 찾은 키워드는 `naver/keywords.md` 에 추가
3. **사실 확인 (매우 중요)**: 가격·할인율·제도·재난·의학 정보는 **웹 검색으로 최신 사실을 확인**하고, 원고 폴더의 `sources.md` 에 출처 URL을 남긴다.
   블로그 주인이 준 정보가 사실과 다르면, **사실대로 고쳐 쓰고** 무엇을 왜 고쳤는지 `memo` 에 적는다.
4. **제목**: 메인 키워드를 앞쪽에. 25~40자. 후보 3개 중 1개 선택, 이유는 `memo` 에.
5. **이미지**: `images.json` → `node scripts/make-images.js <폴더>`
   - `thumbnail` (대표), `list` (요약·체크리스트), `quote` (한 줄 강조), `cta` (CPA 구매 버튼)
   - 실제 사진이 필요한 곳은 `<!-- 📷 직접 사진: ... -->` 로 표시
6. **검수 체크리스트** (하나라도 X면 고친다)
   - [ ] 제목 앞쪽에 메인 키워드
   - [ ] 사실·숫자는 모두 출처 확인됨 (sources.md)
   - [ ] learnings.md 규칙 준수, 최근 글과 주제 중복 없음
   - [ ] (CPA) 광고 표기 문구가 글 맨 위에 있음
   - [ ] 태그 5~10개
7. **저장**: `naver/drafts/YYYY-MM-DD-주제/` 에 `post.md`, `images.json`, `images/`, `sources.md`
   → `node scripts/naver-text.js <폴더>` 로 `붙여넣기.txt` 생성 → 커밋 `원고: 제목`

`post.md` 머리말 형식:
```
---
title: 제목
type: CPA | 홈피드 | 정보
keyword: 메인 키워드
sub_keywords: [보조1, 보조2]
tags: [태그1, 태그2, ...]
link: 판매 링크 (CPA만)
saved: false        # 네이버 임시저장 완료되면 true
published: false    # 발행하면 true
memo: 제목 선택 이유 / 사실과 달라서 고친 부분
---
```

## 3-A. CPA형 템플릿 (판매 전환용 CTA 구조)

블로그 주인이 아래 양식을 주면, 빈칸은 Claude가 조사해서 채운다.

```
제목 :
소주제 : 1) 2) 3) 4) 5)
판매 링크 :
나의 실사용 후기 경험담 :
혜택 :
해당 상품 장점 :
해당 상품을 쓰지 않으면 생기는 문제점 :
참고할 관련 정보 :
```

**작성 규칙**
- **소주제 제목은 받은 단어 그대로** (예: `1) 음식류`). 문장으로 늘리지 않는다.
- 각 소주제 아래 본문은 그 단어에 맞게 **2~3문단**.
- **후기**: 경험을 반드시 강조. 구체적인 사례 + 느낀 점 + **과거와의 비교**.
  "~했었던", "~했었어요" 같은 **과거 시제로 생생하게**. 단순한 기분·특징 나열 금지.
  블로그 주인이 준 경험담을 뼈대로 쓰고, 없는 사건을 지어내지 않는다 (디테일이 더 필요하면 `<!-- ✍️ 직접 쓰기 -->` 로 남긴다).

**CTA 구조 (이 순서로 배치)**
1. **맨 위**: 광고 표기 — `이 포스팅은 제휴 마케팅 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다.` (공정위 추천·보증 심사지침, 필수)
2. **도입 (문제 제기)**: "안 쓰면 생기는 문제"로 공감 → 해결책 예고
3. **CTA ①** (도입 직후): 핵심 혜택 한 줄 + 링크 + `cta` 이미지
4. **소주제 1~5**: 정보로 신뢰 쌓기. 중간(소주제 3 뒤쯤)에 **CTA ②** 텍스트 링크
5. **후기**: 과거 시제 경험담 → "그때 미리 챙겼더라면" 비교
6. **혜택 요약 표/카드**: 장점 · 혜택 · 안 쓰면 손해
7. **CTA ③ (최종)**: 긴급성 + 행동 한 줄 + 링크 + `cta` 이미지
8. **마무리 질문** (댓글 유도)

링크는 3번 이상 넣되, 매번 **다른 문구**로 ("쿠폰 먼저 받아두기", "할인 혜택 확인하기" 등).

## 3-B. 홈피드형 템플릿

```
주제 :
강조 포인트 :
반전 포인트 :
제목에 들어가야 할 핵심 키워드 :
내용 :
```

**작성 규칙**
- 네이버 홈피드는 **첫 화면(썸네일 + 제목 + 첫 3줄)** 이 클릭을 결정한다. 호기심을 주는 훅으로 시작.
- 구조: **훅(3줄)** → 배경 → **반전** → 구체적 정보(소제목 3~4개) → 정리 + 질문
- 핵심 키워드는 제목에 반드시 넣는다.
- ⚠️ **반전·강조 포인트도 사실이어야 한다.** 재난·안전·건강 이슈는 공식 발표(정부·대사관·관광청)로 확인하고,
  사실과 다르면 **같은 키워드를 쓰되 사실에 맞는 반전**으로 바꾼다. (예: "절대 가지마세요?" → "라는 소문, 실제로는…")
  허위 재난 정보는 독자를 속이고, 네이버 신고·저품질의 원인이 된다.

## 3-C. 정보형 템플릿 (매일 자동 기본값)

- 구조: 공감 도입(3~4줄) → 소제목 3~5개 → 핵심 요약 3줄 → 댓글 질문
- 1,500~2,500자, 메인 키워드 본문에 자연스럽게 3~5회
- 블로그 주인만 쓸 수 있는 경험 자리 1~2곳을 `<!-- ✍️ 직접 쓰기: ... -->` 로 남긴다

## 4. 주간 공부 절차 (통계를 받았을 때)

블로그 주인이 네이버 통계 캡처(게시물별 조회수, 유입 검색어, 링크 클릭 수)를 보내면:

1. `naver/stats/YYYY-MM-DD.md` 에 표로 정리
2. **잘 된 글 상위 3개 vs 하위 3개** 비교: 유형(CPA/홈피드/정보), 제목 형태, 키워드, 분량, 이미지 수, CTA 위치, 발행 시간
3. 차이에서 가설을 세우고 `naver/learnings.md` 업데이트
   - 확인됨 → ✅ 검증된 규칙 (근거 숫자·날짜) / 새 가설 → 🧪 시험 중 / 효과 없음 → ❌
4. 블로그 주인에게 요약 3줄 + 다음 주 바꿀 점

> 숫자로 확인된 것만 규칙이 된다. 추측으로 규칙을 바꾸지 않는다.

## 5. 금지 사항
- 판매 링크·가격·할인율·재난 상황을 **지어내거나 과장**하기
- 광고 표기 없이 CPA 글 쓰기
- 다른 글 베끼기, 키워드 도배, 같은 글 중복 발행
- 의학·법률·금융 정보 단정
