# 네이버 블로그 자동 원고 → 임시저장

책 7.2 "바로 66"의 방식(예약 작업 + `draft` 체크)을 네이버 블로그에 맞게 바꾼 구조입니다.

## 전체 흐름

```
[매일 아침 8시]  ☁️ Claude (클라우드, 컴퓨터 꺼져 있어도 됨)
   PROMPT.md + learnings.md 읽기 → 글 쓰기 → 이미지 만들기
   → naver/drafts/날짜-주제/ 에 저장 (saved: false)   ← 1차 임시저장 (GitHub)
        │
[매일 아침 9시]  💻 Claude 데스크톱 앱 (내 컴퓨터, 켜져 있을 때)
   saved: false 인 원고 → 크롬의 네이버 글쓰기 화면에 입력
   → [저장] 버튼만 누름 (발행 X) → saved: true 로 체크   ← 2차 임시저장 (네이버)
        │
[내가 할 일]  📱 네이버 앱 → 글쓰기 → 임시저장 글 열기
   ✍️ 직접 쓰기 자리 채우기 + 📷 내 사진 넣기 → [발행]
        │
[일주일에 한 번]  📊 통계 캡처 보내기 → Claude가 분석해서 learnings.md 업데이트
```

## 폴더 구조

| 파일 | 역할 |
|---|---|
| `PROMPT.md` | 글쓰기·공부 지시서 (맨 아래 "내 블로그 정보"만 채우기) |
| `learnings.md` | 통계로 배운 규칙 (Claude가 매주 업데이트) |
| `stats/` | 주간 통계 기록 |
| `drafts/날짜-주제/post.md` | 원고 (마크다운) |
| `drafts/날짜-주제/붙여넣기.txt` | 네이버에 바로 붙여넣는 텍스트 |
| `drafts/날짜-주제/images/` | 썸네일·요약 카드 이미지 |

## 명령어

```bash
node scripts/make-images.js naver/drafts/<폴더>   # 이미지 만들기
node scripts/naver-text.js  naver/drafts/<폴더>   # 붙여넣기.txt 만들기
```

---

## 💻 네이버 임시저장 자동화 설정 (내 컴퓨터에서 한 번만)

클라우드에서는 네이버에 접속할 수 없어서, **네이버에 넣는 단계는 내 컴퓨터의 Claude가** 합니다.
(책 297쪽처럼 "로컬 작업은 컴퓨터가 켜져 있는 동안에만 실행"됩니다.)

1. 크롬에서 네이버에 **로그인**해 둡니다. (비밀번호는 Claude에게 알려주지 않습니다)
2. Claude 데스크톱 앱에 **Claude in Chrome**(크롬 확장 프로그램)을 연결합니다.
3. 이 저장소를 내 컴퓨터에 받아 두고(`git clone`), Claude 데스크톱 앱 [코드] 탭에서 그 폴더를 엽니다.
4. 아래 프롬프트를 그대로 입력합니다.

```
/schedule 매일 오전 9시에 아래 작업을 하는 스케줄을 설정해줘.

1. git pull 로 최신 원고를 받는다.
2. naver/drafts/ 에서 post.md 의 saved 가 false 인 원고를 찾는다. (없으면 종료)
3. 크롬에서 https://blog.naver.com/ji_hoo_mom 글쓰기 화면을 연다.
4. 제목과 붙여넣기.txt 본문을 넣고, [📷 사진 N] 자리에 images/ 폴더의 같은 번호 이미지를 올린다.
   ([✍️ 직접 쓰기], [📷 직접 사진] 표시는 그대로 남겨둔다 — 내가 채울 자리다)
5. 태그를 넣고, 상단의 [저장] 버튼(임시저장)만 누른다. 절대 [발행]은 누르지 않는다.
6. 임시저장이 확인되면 post.md 의 saved 를 true 로 바꾸고 커밋·푸시한다.
7. 로그인이 풀려 있거나 화면이 예상과 다르면 아무것도 누르지 말고 멈춘 뒤 알려준다.
```

> ⚠️ 처음 몇 번은 옆에서 지켜보면서 제대로 되는지 확인하세요.
> 네이버 화면이 바뀌면 자동 입력이 틀릴 수 있습니다.
> 자동화는 **본인 계정의 임시저장**까지만 쓰고, 대량 자동 발행은 하지 마세요 (저품질·제재 위험).
