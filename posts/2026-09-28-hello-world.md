# 안녕하세요!

이 블로그는 **마크다운 파일**로 글을 쓰면 자동으로 웹페이지가 만들어집니다.

## 이렇게 동작해요

1. `posts` 폴더에 `.md` 파일을 추가합니다.
2. `npm run build`를 실행합니다.
3. `dist` 폴더에 완성된 웹사이트가 생깁니다.

```js
console.log("Hello, blog!");
```

> 앞으로 여기에 글을 차곡차곡 쌓아갈 예정입니다.
