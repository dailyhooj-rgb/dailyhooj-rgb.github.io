오늘은 클로드 코드로 블로그를 만들면서 웹페이지를 이루는 세 가지 기술을 알게 됐다.

## HTML — 내용과 구조

웹페이지의 **뼈대**다. 제목이 어디에 있고, 문단과 이미지가 어디에 들어가는지를 정한다.
브라우저가 폴더를 열면 가장 먼저 찾는 파일이 `index.html`이다.

## CSS — 디자인

HTML 위에 **옷을 입히는** 역할이다. 글자 크기, 색상, 여백, 배경색, 폰트처럼 눈에 보이는 모든 것을 담당한다.
CSS가 없으면 글자만 나열된 밋밋한 페이지가 된다.

## JavaScript — 동작

웹페이지에 **움직임**을 준다. 다크 모드 버튼을 눌렀을 때 배경이 바뀌는 것도 자바스크립트 덕분이다.

## 정리

| 요청 | 담당 |
| --- | --- |
| "내용을 바꿔줘" | HTML |
| "디자인을 바꿔줘" | CSS |
| "동작을 바꿔줘" | JavaScript |

이 구분을 알고 있으면, 클로드에게 수정을 요청할 때 엉뚱한 파일을 고치는지도 알아챌 수 있다.
